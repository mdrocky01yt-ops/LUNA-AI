# 🌙 LUNA AI - Android Assistant

An advanced, premium, futuristic AI Assistant built with Kotlin and Jetpack Compose. 

## Features
- **Futuristic UI:** Glassmorphism, RGB Energy Rings, and a Cosmic Background.
- **AI Chat Engine:** Powered by DeepSeek API (User provides their own API key).
- **Voice System:** Speech-to-Text (Bengali/English) and Text-to-Speech.
- **Device Integration:** Flashlight, Battery check, and more.
- **Memory:** Local Room Database to save chat history.
- **Floating Bubble:** Background assistant bubble (Overlay permission required).
